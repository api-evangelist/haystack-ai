# Haystack GraphQL API

Haystack is an open-source NLP framework. The Deepset Cloud API covers pipeline management, document store operations, querying, user management, evaluation sets, and deployment of NLP search and QA pipelines.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Haystack REST/gRPC API
**Documentation:** https://docs.haystack.deepset.ai
